# 📐 Skill: Tạo Đề Toán & Vật Lý Tương Tự (GDPT 2018) – Lớp 6 Đến 12

> **Trợ lý AI sư phạm cao cấp dành cho Quý Thầy/Cô Giáo Viên Việt Nam trên Google Antigravity.**  
> Tự động phân tích đề gốc, đổi mới bộ số liệu nghiệm đẹp, vẽ 100% hình vẽ kỹ thuật 300 DPI siêu nét, xuất file Word chuẩn **MathType OLE (cỡ chữ 14pt)** click đúp sửa ngay, và tạo bộ 4 mã đề kèm phiếu trả lời bong bóng chuẩn A4 chấm thi tự động.

---

## ✨ Tính Năng Nổi Bật

| Tính năng | Chi tiết kỹ thuật |
| :--- | :--- |
| 🧮 **Môn Toán (Lớp 6 – 12)** | Giữ đúng ma trận đề thi; số liệu nghiệm đẹp, nguyên, không lẻ; bẫy trắc nghiệm sư phạm chuẩn xác |
| ⚡ **Môn Vật Lý (Lớp 6 – 12)** | Kiểm định chuẩn định luật vật lý (bảo toàn năng lượng, khúc xạ ánh sáng, mạch điện, dao động, khí lý tưởng) |
| 🖼️ **Hình vẽ 300 DPI siêu nét** | Nét vẽ đậm rõ (lw=2.2–2.4), độ tương phản cao, nhãn $x, y$ đặt sát mũi tên trục, font số 12–13pt in ra không bị mờ; Bảng biến thiên full viền 100% |
| 📝 **MathType OLE nguyên bản** | Toàn bộ văn bản và công thức đạt chuẩn **cỡ chữ 14pt**, nhúng nhị phân OLE (`Equation.DSMT4`) mở click đúp sửa ngay |
| 🛡️ **Smart Fallback** | Tự động sinh thêm bản Word Equation (OMML) chuẩn SGK mở mượt mà trên mọi máy không cài MathType |
| 👥 **Tách Đề HS & Lời Giải GV** | Bản Học sinh (không đáp án) và Bản Lời giải chi tiết (bảng đáp án màu sắc + barem điểm) |
| 🔀 **Bộ 4 mã đề hoán vị** | Trộn câu và hoán vị đáp án ABCD theo thuật toán khoa học, không làm lệch đáp án gốc |
| 📋 **Phiếu trả lời bong bóng A4** | Phiếu trả lời trắc nghiệm chuẩn A4 có 4 góc định vị để in ấn và chụp ảnh chấm thi bằng điện thoại |
| 📊 **Excel tổng hợp đáp án** | File Excel 4 sheet màu sắc trực quan, sẵn sàng tra cứu hoặc nạp vào app chấm thi |
| 🚀 **Cài đặt 1-Click** | File `cai_dat_tu_dong.bat` tự nhận diện máy, tự cài ngầm Python và đủ các thư viện cần thiết |
| 🔄 **Cập nhật 1-Click** | File `cap_nhat_tu_dong.bat` tự động kết nối GitHub đồng bộ tính năng mới nhất, **bảo toàn tuyệt đối license bản quyền** |
